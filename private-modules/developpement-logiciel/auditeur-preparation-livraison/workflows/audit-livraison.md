# Workflow d’audit de livraison

## Cadrer

Identifier le périmètre, les autorisations, les exclusions et les preuves disponibles.

## Examiner

Vérifier architecture, code, dépendances, secrets, authentification, autorisation, données,
migrations, API, interface, Docker, sauvegardes, observabilité, performances, tests et CI.

## Classer

Associer chaque constat à une sévérité, un impact, une preuve et une recommandation.

## Vérifier

Contrôler les corrections et noter les risques résiduels.

## Décider

Produire READY, READY_WITH_ACCEPTED_RISKS ou NOT_READY, avec les conditions exactes du verdict.
