# Matrice de preuves

- Périmètre autorisé : documenté et daté.
- Dépendances : inventaire et audit disponibles.
- Secrets : recherche effectuée sans exposition.
- Authentification : tests ou revue fournis.
- Autorisation : règles et cas d’échec vérifiés.
- Données : migrations et rollback vérifiés.
- API : validation et erreurs contrôlées.
- Frontend : parcours principaux testés.
- Docker : ports, volumes, réseaux et images revus.
- Sauvegarde : restauration testée ou limite signalée.
- Observabilité : logs et corrélation vérifiés.
- Tests : résultats et couverture utiles.
- Rollback : procédure applicable.
