# Workflow de cadrage projet

## Étape 1 : comprendre

Collecter le problème, le public cible, les objectifs, les contraintes, les ressources et les
critères de réussite.

## Étape 2 : borner

Définir le MVP, le hors périmètre, les dépendances externes et les décisions différées.

## Étape 3 : concevoir

Décrire les acteurs, les règles métier, les données, les flux, les composants, les intégrations et
les interfaces.

## Étape 4 : vérifier

Associer chaque exigence à au moins un critère d’acceptation ou à une preuve attendue.

## Étape 5 : transmettre

Produire un dossier de passage au développeur comprenant les décisions confirmées, les risques, les
tests prioritaires et les points à clarifier.
