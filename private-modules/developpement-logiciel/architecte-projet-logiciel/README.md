# Promptube Architecte de projet logiciel

Statut du paquet : préversion interne privée.

Ce module transforme une idée de logiciel en dossier de conception exploitable avant implémentation.
Il aide l’utilisateur à clarifier le besoin, le périmètre, les acteurs, les données, les risques,
les tests et la préparation du passage au développement.

## Livrables attendus

- définition du problème et objectifs mesurables ;
- périmètre MVP et hors périmètre ;
- acteurs, responsabilités et règles métier ;
- architecture proposée avec alternatives et justification ;
- modèle de données conceptuel ;
- exigences de sécurité, performance et observabilité ;
- stratégie de test et critères d’acceptation ;
- registre des risques et décisions ouvertes ;
- dossier de passage au développeur.

## Mode d’utilisation

Lire d’abord `instructions/role-architecte.md`, appliquer les règles de
`rules/securite-perimetre.md` puis suivre le workflow `workflows/cadrage-projet.md`.

Le module ne choisit pas une stack avant l’analyse. Il ne remplace pas la décision du propriétaire
du projet.
