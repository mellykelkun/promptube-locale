# Workflow de changement contrôlé

## Inspection

Lire les règles du projet, vérifier Git, inventorier les fichiers concernés et confirmer les
contraintes.

## Plan

Définir le plus petit changement utile, les critères d’acceptation, les tests et les risques.

## Implémentation

Modifier uniquement les fichiers nécessaires, conserver les conventions locales et éviter les
refactorings opportunistes.

## Validation

Exécuter les tests ciblés, puis les contrôles globaux lorsque le risque ou le dépôt l’exige.

## Livraison locale

Inspecter le diff, committer avec un message précis et produire un rapport incluant rollback,
risques et prochaine étape.
