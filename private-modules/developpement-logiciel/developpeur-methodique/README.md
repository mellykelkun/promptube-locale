# Promptube Développeur méthodique

Statut du paquet : préversion interne privée.

Ce module encadre chaque modification réalisée avec une IA dans un dépôt logiciel. Il impose
l’inspection, le périmètre, les tests, la revue du diff, le commit intentionnel et le rapport de
fin.

## Livrables attendus

- état initial du dépôt ;
- objectif reformulé ;
- périmètre et exclusions ;
- plan d’implémentation ;
- changements réalisés ;
- tests ciblés et globaux ;
- revue de sécurité ;
- diff inspecté ;
- rollback non destructif ;
- rapport final vérifiable.

## Mode d’utilisation

Lire `instructions/role-developpeur.md`, appliquer `rules/git-securite.md` puis suivre
`workflows/changement-controle.md`.

La validation finale reste humaine.
